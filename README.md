## ⚡ Principais Recursos

- 👥 **Campanha em Dupla:** Jogue as missões da história do GTA V juntos, entrando nos mesmos carros, realizando assaltos e trocas de tiro.
- ◫ **Tela Dividida Dinâmica:** Pressione `[K]` para alternar entre tela única compartilhada ou tela dividida (horizontal ou vertical).
- 🎮 **Suporte a Múltiplos Controles:** Conecte 2 controles USB/Bluetooth (Xbox, PlayStation, genéricos) ou jogue no Teclado/Mouse (P1) e Controle (P2).
- 🇧🇷 **100% em Português (PT-BR):** Menus, avisos, notificações e configurações totalmente traduzidos.
- 🎨 **Padrão Visual DLuz Games:** Menu in-game estilizado com arte oficial do canal gerada com Nano Banana 2.
- 🛡️ **Segurança Anti-Ban:** Modo exclusivo para o singleplayer offline. Desinstalador 1-clique que limpa o jogo para voltar ao GTA Online sem riscos.

## 🎮 Controles & Atalhos no Jogo

| Tecla / Atalho | Ação no Jogo |
| :--- | :--- |
| **`[ N ]`** ou **`[ Start no Controle 2 ]`** | **Spawna ou remove o Jogador 2** instantaneamente ao seu lado. |
| **`[ Page Up ]`** | Abre o **Menu de Ajustes do Mod** (armas, skins, mira lock-on e controles). |
| **`[ K ]`** | Ativa ou altera a **Tela Dividida (Splitscreen)**. |
| **`[ F4 ]`** | Abre o **Native Trainer oficial** *(Exclusivo Versão PRO)*. |
| **`[ * no Teclado ]`** | Alterna entre **Modo Cooperativo** (aliados) e **Modo Duelo (PVP)**. |
| **`[ . no Teclado Numérico ]`** | Trava a mira automaticamente no alvo mais próximo (Lock-On). |
| **`[ 0 no Teclado Numérico ]`** | Agacha ou levanta com o Jogador 2. |

## 🚀 Como Instalar

1. Baixe o instalador oficial: **`DLuz_GTA5_Cooperativo_Instalador.exe`**.
2. Abra o executável. Ele detectará a pasta do seu GTA V automaticamente (Steam, Epic Games ou Rockstar).
3. *(Opcional)* Se tiver uma chave PRO, cole no campo de ativação e clique em **⚡ Ativar Chave PRO**.
4. Clique em **⚡ INJETAR E INSTALAR MOD COOP**.
5. Abra o jogo normalmente e divirta-se!
